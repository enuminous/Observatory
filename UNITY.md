A program compiling all physical ontologies must distinguish a shared vocabulary from an actual physical correspondence.

**U1. Dynamical limit:** for a defined partial reduction map `r_i`, compare compatible evolved states under a declared metric:

```text
d_i(r_i(T_U^t u), T_i^t(r_i(u))) ≤ ε_i(t,u)
```

**U2. Measured observable:** compare the candidate's observable map with the well-tested sector's readout in its domain:

```text
d_Y(A_i^U(u), A_i(r_i(u))) ≤ δ_i(u)
```

**U3. Distinct new effect:** test a predeclared measurable difference against strong conventional null models:

```text
Δy = y_candidate − y_conventional
```

These are criteria for a future test, **not proved results**. They require defined domains, constants, symmetries, boundary conditions, uncertainty models, matched comparators, frozen hypotheses, and independent experimental replication.
